# 数据质量检查

`DataQualityService` 可检查 Mock 或真实 `MarketDataProvider` 的基础质量。

已检查内容：

- 股票列表必填字段：symbol、code、exchange、name、listed_date
- 股票列表重复代码数量
- 最新行情：价格、昨收、成交量、成交额、时区和延迟
- 五档盘口：买卖五档数量、价格和委托量非负
- 真实响应为空、HTML 拦截页、字段数量变化、无效数值和异常时间戳

历史真实接口验收记录（日期不参与程序逻辑）：

- 腾讯最新价和五档盘口：通过。
- AkShare 日线：东方财富主源成功过，也观察到企业代理偶发断连；新浪备用通过。
- AkShare 交易日历：通过。
- 上交所主板、科创板和深交所 A 股列表：合计 5202 只，测试代码要求大于 5000 且包含 `600519.SH`。

测试分为两层：固定响应测试不依赖网络，每次 CI 都运行；`RUN_REAL_MARKET_DATA_TESTS=1` 时额外运行真实网络测试。真实测试失败只能说明当前网络或上游接口不可用，程序必须显示异常并停止使用过期行情，不能伪造字段。
