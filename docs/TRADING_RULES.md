# 交易规则

当前已实现并测试：

- A股代码和交易所识别：支持 `600519`、`600519.SH`、`000001.SZ` 等形式。
- 板块识别：主板、创业板、科创板。
- 交易时段判断：集合竞价、连续竞价、午间休市、收盘后、非交易日。
- 普通A股买入数量必须是 100 股整数倍。
- 卖出允许处理不足 100 股的零股尾仓。
- T+1：当日买入股票当日不能卖出。
- 主板 10%、创业板/科创板 20% 的涨跌停规则；ST 股票识别后直接排除交易。
- ST、退市整理、已退市和上市不足 60 日股票禁止模拟成交。
- 停牌不得成交。
- 涨停无法买入、跌停无法卖出。
- 行情时效按 current_time - quote_time 动态计算，未来行情或超过 30 秒的行情不得撮合。
- NEXT_OPEN 订单在提交当日保持等待，最早在下一交易日 09:30 后进入撮合。
- 成交量参与率限制导致的部分成交会保存 filled_quantity 和 remaining_quantity，后续可继续撮合。
- 无盘口数据时使用参考价加统一价格调整的降级撮合，并在结果中标注。

当前已实现并测试的交易成本：

- 买卖佣金
- 最低佣金
- 卖出印花税
- 过户费
- 滑点
- 市场冲击成本
- 成交量参与率上限

滑点和市场冲击只反映在成交价与参考价的差额中；现金不再重复扣除这两项。现金费用仅包括佣金、印花税和过户费，Fill 同时保存所有成本分项。

当前已实现并测试的风控：

- 单股 30% 仓位限制
- 总仓位 90% 限制
- 最大回撤 15% 暂停新增买入
- 风控触发后仍允许卖出
- 可用现金不足拦截

账户每日生成 PortfolioSnapshot，持续更新历史峰值、当前回撤和最大回撤。风控只读取账户真实当前回撤；达到 15% 后拒绝新增买入，卖出不受该暂停限制。订单状态、剩余数量、成交、费用和净值回撤均持久化并可在应用重启后恢复。
