# 交易规则

当前已实现并测试：

- A股代码和交易所识别：支持 `600519`、`600519.SH`、`000001.SZ` 等形式。
- 板块识别：主板、创业板、科创板。
- 交易时段判断：集合竞价、连续竞价、午间休市、收盘后、非交易日。
- 普通A股买入数量必须是 100 股整数倍。
- 卖出允许处理不足 100 股的零股尾仓。
- T+1：当日买入股票当日不能卖出。
- 主板 10%、创业板/科创板 20%、ST 5% 的涨跌停规则。
- 上市不足 60 日股票标记为“规则不确定”，禁止强制模拟成交。
- 停牌不得成交。
- 涨停无法买入、跌停无法卖出。
- 行情过期时订单顺延。
- 成交量参与率限制导致的部分成交。
- 无盘口数据时使用最新价加滑点的降级撮合，并在结果中标注。

当前已实现并测试的交易成本：

- 买卖佣金
- 最低佣金
- 卖出印花税
- 过户费
- 滑点
- 市场冲击成本
- 成交量参与率上限

当前已实现并测试的风控：

- 单股 30% 仓位限制
- 总仓位 90% 限制
- 最大回撤 15% 暂停新增买入
- 风控触发后仍允许卖出
- 可用现金不足拦截
