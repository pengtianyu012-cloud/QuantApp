# 用户指南

## 启动软件

```powershell
.\.venv\Scripts\python.exe main.py
```

## 当前可用内容

- 可打开 PySide6 桌面主窗口。
- 总览仪表盘显示市场状态、数据源、行情延迟、账户资产、现金、持仓市值和风控状态。
- 实时行情页显示自选股最新价、涨跌幅、成交量、成交额、换手率、行情时间和五档盘口。
- 市场数据页显示沪深A股主表、ST排除状态、上市日期和数据更新时间。
- 模拟交易页支持手工模拟买入/卖出，订单不会发送到券商。
- 账户、持仓、订单和成交保存到 SQLite，应用重启后自动恢复。
- 系统设置页显示交易成本和刷新参数。
- 策略中心可生成 Mock 策略信号，并刷新选股结果页。
- 历史回测页可运行 T 日收盘信号、T+1 开盘成交的基础回测。
- 日志与诊断页显示依赖状态和日志位置。

## 真实研究行情

默认使用完全离线的 Mock 数据。启用已验证的公开研究数据源：

```powershell
$env:QUANT_APP_DATA_PROVIDER = "public"
.\.venv\Scripts\python.exe main.py
```

真实模式使用 AkShare 获取沪深股票主表、日线和交易日历，并使用腾讯公开网页行情获取最新价与五档盘口。自选股默认每 3 秒在后台线程刷新；全市场主表使用低频缓存，不做高频全量抓取。

五档买量和卖量是未成交委托量，不是主动买入或主动卖出成交量。数据源不支持的委比、委差和精确到股成交量显示为“不支持”，不会补造数值。公开网页行情仅适合本地学习研究，不保证商业授权、稳定性或服务等级。

## 手工模拟下单

1. 打开“模拟交易”页。
2. 输入股票代码、限价和数量。
3. 点击“模拟买入”或“模拟卖出”。
4. 确认二次弹窗中的模拟交易免责声明。
5. 成功后持仓、订单和成交表会更新。

默认模式使用 Mock 行情；真实研究模式只允许使用未过期的已验证行情进行模拟撮合。休市后行情超过 30 秒会被判定为过期并禁止成交。所有订单只写入本地模拟账户，不连接真实券商。

## 策略预览

打开“策略中心”，点击“生成收盘信号预览”，系统会使用 Mock 日线和财务指标运行基础策略逻辑，并在“选股结果”页展示策略名称、代码、评分、入选原因和建议仓位。

## 当前限制

- 真实分时图和可靠历史财务披露时点
- 完整卖出、组合再平衡、分红送股与复权现金处理
- 真实沪深300基准曲线
- CSV 导出和诊断导出

未实现能力在界面中会显示“尚未实现”或明确风险提示。
