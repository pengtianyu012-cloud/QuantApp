# 用户指南

## 启动软件

```powershell
.\.venv\Scripts\python.exe main.py
```

## 当前可用内容

- 可打开 PySide6 桌面主窗口。
- 总览仪表盘显示市场状态、动态行情延迟、账户资产、现金、持仓市值、当前/最大回撤、累计费用和风控状态。
- 实时行情页显示自选股最新价、涨跌幅、成交量、成交额、换手率、行情时间和五档盘口。
- 市场数据页显示沪深A股主表、ST排除状态、上市日期和数据更新时间。
- 模拟交易页支持手工模拟买入/卖出，订单不会发送到券商。
- 账户、持仓、订单状态事件、成交、每日净值和回撤保存到 SQLite，应用重启后自动恢复。
- 系统设置页显示交易成本和刷新参数。
- 策略中心使用当前模式的行情源生成策略信号，并刷新选股结果页。
- 服务层支持交易日收盘后持久化信号并幂等生成下一交易日 NEXT_OPEN 本地模拟订单。
- 历史回测页可运行 T 日收盘信号、T+1 开盘成交的基础回测。
- 日志与诊断页显示依赖状态和日志位置。

## 运行模式

默认的 mock 模式使用完全离线数据并允许本地模拟订单。启用真实公开研究行情：

```powershell
$env:QUANT_APP_MODE = "research"
.\.venv\Scripts\python.exe main.py
```

research 模式允许策略研究和回测，但禁止手工下单。需要使用真实公开行情执行本地模拟订单时：

```powershell
$env:QUANT_APP_MODE = "paper"
.\.venv\Scripts\python.exe main.py
```

research 和 paper 使用 AkShare 获取沪深股票主表、日线和交易日历，并使用腾讯公开网页行情获取最新价与五档盘口。两种模式都禁止隐式使用 Mock；上游失败时显示异常，不用 Mock 价格继续。自选股默认每 3 秒在后台线程刷新；全市场主表使用低频缓存，不做高频全量抓取。

五档买量和卖量是未成交委托量，不是主动买入或主动卖出成交量。数据源不支持的委比、委差和精确到股成交量显示为“不支持”，不会补造数值。公开网页行情仅适合本地学习研究，不保证商业授权、稳定性或服务等级。

## 手工模拟下单

1. 打开“模拟交易”页。
2. 输入股票代码、限价和数量。
3. 点击“模拟买入”或“模拟卖出”。
4. 确认二次弹窗中的模拟交易免责声明。
5. 成功后持仓、订单和成交表会更新。

mock 和 paper 模式可以手工模拟下单，research 模式禁止下单。paper 只允许使用未过期的已验证真实行情撮合；休市后行情超过 30 秒会被判定为过期并顺延订单。NEXT_OPEN 订单提交当日不会成交，停牌或涨跌停无法成交时保留订单到后续交易日重试。所有订单只写入本地模拟账户，不连接真实券商。

订单表显示订单类型、已成交量、剩余量和可撮合时间。成交表分别显示参考价、成交价、佣金、印花税、过户费、滑点和市场冲击；滑点与市场冲击已进入成交价，不会再从现金重复扣除。

## 策略预览

打开“策略中心”，点击“生成收盘信号预览”，系统会使用当前模式配置的行情 provider 运行基础策略逻辑，并在“选股结果”页展示策略名称、代码、评分、入选原因和建议仓位。

当前按钮仍是预览，不会自动创建订单。收盘持久化与 NEXT_OPEN 编排已在服务层实现并有测试覆盖；桌面定时触发、开盘批量续撮和取消/过期策略尚未接入 UI。research 模式即使执行服务层收盘任务，也只保存信号并标记跳过派单。

## 数据库升级

SQLite 数据库会在启动时按版本顺序事务升级到 v4。升级保留既有订单和成交；v3 增加订单状态、成本和净值回撤，v4 增加信号派发账本及订单 signal_id 唯一关联。升级前建议备份数据库，详细说明见 MIGRATION_PHASE0.md 和 MIGRATION_PHASE1.md。

## 当前限制

- 真实分时图和可靠历史财务披露时点
- 完整卖出、组合再平衡、分红送股与复权现金处理
- 真实沪深300基准曲线
- CSV 导出和诊断导出
- 收盘任务桌面定时触发、开盘批量续撮和订单取消/过期策略

未实现能力在界面中会显示“尚未实现”或明确风险提示。
