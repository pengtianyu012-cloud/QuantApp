# 用户指南

## 启动软件

```powershell
.\.venv\Scripts\python.exe main.py
```

## 当前可用内容

- 可打开 PySide6 桌面主窗口。
- 总览仪表盘显示 Mock 市场状态、数据源、账户资产、现金、持仓市值和风控状态。
- 实时行情页显示 Mock 自选股最新价、涨跌幅、成交量、成交额、换手率和行情时间。
- 市场数据页显示 Mock 沪深A股样例、ST排除状态和上市日期。
- 模拟交易页支持手工模拟买入/卖出，订单不会发送到券商。
- 系统设置页显示交易成本和刷新参数。
- 日志与诊断页显示依赖状态和日志位置。

## 手工模拟下单

1. 打开“模拟交易”页。
2. 输入股票代码、限价和数量。
3. 点击“模拟买入”或“模拟卖出”。
4. 确认二次弹窗中的模拟交易免责声明。
5. 成功后持仓、订单和成交表会更新。

当前下单使用 Mock 行情、阶段3撮合内核和风控内核；不会连接真实券商，不会执行真实订单。
