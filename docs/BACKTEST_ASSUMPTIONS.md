# 回测假设

当前已实现日线回测骨架，并通过 Mock 与 provider 注入测试：

- 日线策略在 T 日收盘后生成信号。
- 模拟成交参考 T+1 交易日开盘价，并使用与模拟盘一致的滑点/市场冲击价格调整。
- 现金只额外扣除佣金、印花税和过户费，价格影响不重复作为费用扣除。
- 回测循环只向策略传入当前 bar 及之前的可见数据。
- 策略与回测使用当前运行模式配置的同一个 MarketDataProvider，真实模式不回退 Mock。
- 当前仅支持基础买入演示，不含完整组合再平衡、卖出规则、分红送股、复权和沪深300真实基准。

后续回测必须继续遵守：

- 默认回测最近 5 年，开始与结束日期由注入 Clock 动态推导。
- 默认基准为沪深300。
- 不得使用未来数据。
- 财务因子必须按可获得日期使用。
- 如果免费数据无法消除幸存者偏差或披露时点风险，必须在结果页面显示风险提示。
- 复权价格仅用于策略分析，成交和现金计算使用一致、可解释的价格体系。
